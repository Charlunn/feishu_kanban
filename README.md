# 飞书 AI 交付战情看板

三人创业团队的飞书内嵌任务看板。打开就是工具，不是营销页。

## 核心功能

- **飞书免登** — 在飞书中打开自动识别身份，无需手动选择
- **拖拽流转** — 手机触摸/桌面鼠标拖拽卡片完成状态流转
- **到期提醒** — 任务设置截止时间后，临期/超期自动推送飞书消息
- **人工复核** — 客户可见、报价、AI草稿等高风险任务必须经过复核
- **WIP 限制** — 每人最多同时推进 2 个任务，避免过载

## 工作流

```
任务池 → 可领取 → 已认领 → 进行中 → 阻塞/待复核 → 已完成
```

## 业务场景

| 任务类型 | 典型场景 |
|---------|---------|
| 线索跟进 | 官网诊断表来了新线索，需要判断是否进入深度诊断 |
| 诊断复核 | AI 生成的诊断报告结论需要人工确认评分和措辞 |
| 交付验收 | 客户交付文件夹模板、验收清单需要另一人检查 |
| 报价确认 | 试点报价的包含项/排除项需要负责人口径确认 |
| 内部运营 | 敏感资料规范、流程文档等内部事务 |
| 飞书集成 | 看板推送、卡片动作、定时任务等技术工作 |

## 飞书集成

### 登录

在飞书内嵌网页中打开时，自动调用 `tt.requestAuthCode()` 获取授权码，后端换取 user_access_token 识别身份。

预览模式（非飞书环境）下可手动切换身份。

### 到期提醒

- 任务创建时可设置截止时间
- `POST /api/feishu/reminders` 扫描即将到期（≤4小时）和已超期的任务
- 向负责人推送飞书卡片消息，超期任务同时通知创建者
- 建议通过飞书定时任务每小时调用一次

### 每日摘要

`POST /api/feishu/push-digest` 向团队群推送看板摘要卡片。

### 卡片动作

飞书卡片上的按钮（领取、开始、交复核、通过）直接调用看板 API。

## API 路由

| 路由 | 用途 |
|------|------|
| `GET /api/tasks` | 获取看板状态 |
| `POST /api/tasks` | 创建任务 |
| `POST /api/tasks/[id]/claim` | 认领任务 |
| `POST /api/tasks/[id]/move` | 流转任务 |
| `POST /api/feishu/login` | 飞书免登 |
| `POST /api/feishu/events` | 飞书事件回调 |
| `POST /api/feishu/card-actions` | 卡片动作回调 |
| `POST /api/feishu/push-digest` | 推送每日摘要 |
| `POST /api/feishu/reminders` | 到期提醒检查 |

## 数据边界

不要在任务描述中粘贴客户名单、身份证号、银行卡、合同原件、密码或 API Key。涉及客户可见内容或 AI 输出的任务必须经过复核。
